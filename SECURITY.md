# Security

## Supported versions

Only the [latest release](https://github.com/Dudiebug/couchliteos/releases/latest) gets
security fixes. Update from Settings > SOFTWARE UPDATE (0.2.1 and newer), or reinstall from
the latest ISO.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub:
[Security > Report a vulnerability](https://github.com/Dudiebug/couchliteos/security/advisories/new).

Include the CouchLiteOS version, what an attacker could do, and the steps to reproduce it.
You should hear back within a week. Once a fix is released, the advisory is published and
you are credited unless you ask not to be.

Problems in the apps CouchLiteOS ships (Moonlight, chiaki-ng, Firefox, Google Chrome,
Tailscale, FreeRDP) should also be reported to those projects.
