# Troubleshooting

This page moved to the wiki: [Troubleshooting](https://github.com/Dudiebug/couchliteos/wiki/Troubleshooting).

- **An update broke the box?** Settings > SOFTWARE UPDATE > RESTORE PREVIOUS
  VERSION, or, if it no longer starts, the boot menu entry
  "CouchLiteOS: restore previous version"
  ([details](https://github.com/Dudiebug/couchliteos/wiki/Troubleshooting#the-update-broke-my-box)).
- **A text menu instead of the TV home screen?** The TV interface could not
  start, so the box started the classic interface by itself
  ([details](https://github.com/Dudiebug/couchliteos/wiki/Troubleshooting#the-classic-interface)).
