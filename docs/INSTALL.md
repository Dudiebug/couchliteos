# Installing CouchLiteOS

This page moved to the wiki: [Install](https://github.com/Dudiebug/couchliteos/wiki/Install).

In short:

- A disk of 32 GB or more is recommended: every update keeps the system it
  replaces (about 2 GB), and needs about 7 GB free to save it
  ([Disk space](https://github.com/Dudiebug/couchliteos/wiki/Install#disk-space)).
- The download no longer includes a web browser. You pick Firefox or Google
  Chrome during setup, or later in Settings > APPLICATIONS > ADD A WEB BROWSER,
  and it installs from the internet.
- CouchLiteOS 0.2.0 or MoonlightOS already installed? Boot the new USB stick and
  choose Settings > SOFTWARE UPDATE > UPDATE THE INSTALLED SYSTEM instead of
  reinstalling ([Updating](https://github.com/Dudiebug/couchliteos/wiki/Updating#updating-an-older-install-from-the-usb-stick)).
