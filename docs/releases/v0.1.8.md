# MoonlightOS v0.1.8

MoonlightOS v0.1.8 makes the boot menu clearer and improves the guides for
installing and for live USB sticks.

## New

- **Clearer boot menu.** The Live and Install entries are named clearly.
- **Live without persistence.** A new boot entry starts the live system without
  saving anything, for troubleshooting or a one-off session.
- **Clearer persistence guide.** It now gives separate folders for MoonlightOS
  settings, logs, Tailscale, and Bluetooth, and explains how live USB sets them
  up.
- **Rufus and Ventoy instructions** for writing the USB stick.

## Known limitations

- Installing to NVMe or SATA drives or to a second USB stick, Rufus, Ventoy,
  and persistent live USB sticks have not yet been tried on real hardware.
