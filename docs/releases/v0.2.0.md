# CouchLiteOS v0.2.0

CouchLiteOS is the new name of MoonlightOS. v0.2.0 is the first release under
that name. It adds a guided setup wizard, Wi-Fi setup from the controller, sleep,
TV control over HDMI-CEC, waking the gaming PC, and many controller and
usability fixes. This is a **draft**: publish it only after the hardware
checklist in `docs/TESTING.md` passes.

## Downloads

| File | Hardware |
|---|---|
| `couchliteos-0.2.0-amd64.iso` | General: Intel and AMD graphics, NVIDIA Kepler and older (including the iMac Late 2013), Intel Macs, VMs |
| `couchliteos-0.2.0-nvidia-amd64.iso` | NVIDIA GeForce GTX 745/750 and 900 to RTX 40 (Maxwell to Ada); falls back to nouveau on other GPUs |

## New name

- Everything is renamed: the project, the ISO files, paths
  (`/var/lib/couchliteos`, `/var/log/couchliteos`), services, the appliance
  user, and kernel options (`couchliteos.*`).
- A live USB stick made for MoonlightOS keeps its settings and pairings. At boot,
  if the old persistence folders are present, CouchLiteOS mounts them in place of
  the new ones. New sticks use the new `persistence.conf` lines in
  `docs/INSTALL.md`.
- People who finished setup on an older version see a one-time "what's new"
  screen that explains the new name.

## Setup wizard

- A guided first-boot setup, also in Settings > SETUP WIZARD: network, controller,
  sound, and gaming PC pairing. Running it again redoes only the steps that are
  not done.
- Wi-Fi: joins hidden networks, says why the network list is empty, reports a
  wrong password as one (and does not save it), keeps a working connection when
  setup runs again, and no longer fails the internet check because a router
  ignores ping.
- Controller: Bluetooth scanning stops once the controller is paired.
- Sound: the original output comes back unless the test tone was heard.
- Gaming PC: the PIN is shown large; a PC counts as paired only if this attempt
  paired it; an unreachable PC is explained instead of a generic failure.

## Everyday use

- Settings > NETWORK joins Wi-Fi with the controller (the wizard's network step);
  ADVANCED NETWORK SETTINGS still opens the keyboard tool.
- The home screen shows whether the gaming PC is reachable, and a
  NO CONTROLLER FOUND banner when no controller is connected.
- Settings > CONTROLLER BUTTONS shows what each button does, for Xbox,
  PlayStation, and Nintendo-style controllers.
- Sleep: hold Guide / PS for 3 s, or use SLEEP on the home screen (it asks first).
- Auto-stream to a chosen gaming PC at start, and WAKE PC (Wake-on-LAN).
- TV control over HDMI-CEC: turn the TV on and switch its input; the TV remote
  moves around the launcher.

## Fixes

Four bug-hunt passes and two usability passes over the launcher, app start and
stop, and the controller: clearer error screens with a retry, menus that scroll on
720p TVs, a font sized for the screen (720p to 4K), and many smaller fixes.

## Hardware-specific features

Features that need specific hardware are checked on the machine each time it
starts, because one USB stick moves between PCs. On a PC without the hardware,
the feature is shown as unavailable with a reason and can't be turned on. A
setting saved on another PC is kept but ignored until the stick returns there.

## Moved to v0.2.1

Finished on their own branches but not merged in time for this build: a
5-second sleep hold that never sleeps during a game, TV remote keys reaching
running apps, fit-to-screen (overscan), easier-use hints, the couch-to-game flow
updates, faster boot, and SMOOTHER STREAM / PAIR ANOTHER GAMING PC.

## Testing status

Both ISOs are built from commit `5ed2024`. At that commit the full `make test`
(static checks, 1048 launcher unit tests, and the other suites) passed in the
Debian 13 build VM.

QEMU live smoke test passed on both ISOs: live boot, launcher and setup
readiness, and every configured app started (Moonlight, Chiaki-ng, Firefox,
Google Chrome, Remote Desktop), plus the on-screen keyboard, Bluetooth, and
USB/IP. The QEMU persistence and install-to-disk tests were **not run** on these
ISOs because of the release deadline.

Not yet tested on real hardware: sleep and resume (including NVIDIA),
Bluetooth, USB-keyboard, and Wake-on-LAN wake, HDMI-CEC with real TVs and
Pulse-Eight adapters, Secure Boot, Wi-Fi joining, controller pairing, Moonlight
PIN pairing, NTFS sticks, rfkill, GRUB on hardware, font size and overscan on a
real TV, and real Sunshine wake timing.
