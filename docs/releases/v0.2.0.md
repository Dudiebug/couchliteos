# CouchLiteOS v0.2.0

CouchLiteOS is the new name of MoonlightOS, and v0.2.0 is the first release
under that name. It adds a guided setup wizard, Wi-Fi setup from the
controller, sleep, TV control over HDMI-CEC, waking the gaming PC, and many
controller and usability fixes.

## Downloads

| File | Hardware |
|---|---|
| `couchliteos-0.2.0-amd64.iso` | General: Intel and AMD graphics, NVIDIA Kepler and older (including the iMac Late 2013), Intel Macs, VMs |
| `couchliteos-0.2.0-nvidia-amd64.iso` | NVIDIA GeForce GTX 745/750 and 900 to RTX 40 (Maxwell to Ada); falls back to nouveau on other GPUs |
| `SHA256SUMS` | Checksums for both ISOs |

## New

- **New name.** MoonlightOS is now CouchLiteOS. The ISO files, folders
  (`/var/lib/couchliteos`, `/var/log/couchliteos`), and boot options
  (`couchliteos.*`) use the new name.
- **MoonlightOS live sticks keep working.** A live USB stick made for
  MoonlightOS keeps its settings and pairings. New sticks use the new
  `persistence.conf` lines in `docs/INSTALL.md`.
- **What's new screen.** If you finished setup on an older version, a one-time
  screen explains the new name.
- **Setup wizard.** A guided first-boot setup for network, controller, sound,
  and gaming PC pairing, also in Settings > SETUP WIZARD. Running it again
  redoes only the steps that are not done.
- **Wi-Fi in setup.** Joins hidden networks, says why the network list is
  empty, reports a wrong password as one (and does not save it), keeps a
  working connection when setup runs again, and no longer fails the internet
  check because a router ignores ping.
- **Controller, sound, and PC steps.** Bluetooth scanning stops once the
  controller is paired. The original sound output comes back unless you heard
  the test tone. The pairing PIN is shown large, a PC counts as paired only if
  this attempt paired it, and an unreachable PC is explained.
- **Wi-Fi from the controller.** Settings > NETWORK joins Wi-Fi with the
  controller. ADVANCED NETWORK SETTINGS still opens the keyboard tool.
- **Home screen status.** Shows whether the gaming PC is reachable, and a NO
  CONTROLLER FOUND banner when no controller is connected.
- **Controller button help.** Settings > CONTROLLER BUTTONS shows what each
  button does on Xbox, PlayStation, and Nintendo-style controllers.
- **Sleep.** Hold Guide / PS for 3 seconds, or use SLEEP on the home screen
  (it asks first).
- **Auto-stream and WAKE PC.** Start streaming to a chosen gaming PC at start,
  and wake it with Wake-on-LAN.
- **TV control over HDMI-CEC.** Turn the TV on and switch its input; the TV
  remote moves around the launcher.
- **Hardware features follow the PC.** Features that need specific hardware
  are checked each time the box starts, because one USB stick can move between
  PCs. Without the hardware, the feature shows as unavailable with a reason. A
  setting saved on another PC is kept but ignored until the stick is back
  there.

## Fixed

- **Launcher, app start and stop, and controller.** Clearer error screens with
  a retry, menus that scroll on 720p TVs, text sized for the screen (720p to
  4K), and many smaller fixes.

## Known limitations

- Sleep and wake, HDMI-CEC TV control, Wi-Fi joining, controller pairing, and
  Moonlight PIN pairing have not yet been tried on real hardware.
- Installing to disk and live USB persistence were not checked for this
  release.

## Updating

This release has no in-place update; install it fresh. To move from 0.2.0 to a
newer release, reinstall once; after that, updates come from Settings >
SOFTWARE UPDATE. See [Updating](https://github.com/Dudiebug/couchliteos/wiki/Updating)
in the wiki.
