# MoonlightOS v0.1.1

MoonlightOS v0.1.1 adds Firefox ESR. Firefox opens from the same
controller-friendly launcher as Moonlight and chiaki-ng and keeps its profile
after installation.

## Downloads

Verify the download before writing it to USB:

```bash
sha256sum --check moonlightos-0.1.1-amd64.iso.sha256
```

See the repository README and `docs/INSTALL.md` for installation instructions.

## New

- **Firefox ESR** from Debian 13's signed repositories, running natively on
  Wayland.
- **Full Firefox browsing**, with bookmarks, history, downloads, and settings
  kept between sessions.
- **Firefox in the launcher**, next to Moonlight and chiaki-ng.
- **All three apps return to the launcher** when they close or crash.

## Known limitations

- Not yet tried on the target Dell OptiPlex, including video
  decoding, display audio, gamepads inside Firefox, USB/IP, and streaming quality.
- Wi-Fi, Bluetooth setup, HDR, and a general-purpose desktop are not included.
- A live USB is for trying MoonlightOS; install to the SSD to keep your data.
