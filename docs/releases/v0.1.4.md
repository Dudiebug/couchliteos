# MoonlightOS v0.1.4

MoonlightOS v0.1.4 improves saving a support file to USB and makes export
failures visible, so you always know whether it worked.

## Downloads

Verify the downloaded image before writing it:

```bash
sha256sum --check moonlightos-0.1.4-amd64.iso.sha256
```

## New

- **Export progress screen.** Settings shows a full-screen progress view with a
  spinner and progress bar while the support file is collected and written.
- **Destination and time.** The screen shows the chosen USB drive and how long
  the export has taken.
- **A clear result every time.** The screen stays up until the export
  succeeds, fails, or times out.
- **Clear error messages** when no writable USB drive is found, the export
  cannot start, the export fails, or it takes too long.
- **Saved file location.** After a successful export, the screen shows exactly
  where the file was saved.

The support file is still saved the same careful way: sensitive values are
removed, the file is checked, a checksum file is written next to it, and the
drive is synced before success is shown.

Moonlight 6.1.0, chiaki-ng 1.10.0, and Firefox ESR are unchanged.

## Known limitations

- Exporting to real USB drives and the new progress screen have not yet been
  tried on the target hardware.
