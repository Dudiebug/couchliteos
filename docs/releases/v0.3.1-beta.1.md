# CouchLiteOS v0.3.1-beta.1

**A beta for 0.3.1.** It lets you type into any app from your phone with one
controller shortcut, and puts 4K TVs that started in 1080p back in 4K.
Please report what goes wrong on
[GitHub](https://github.com/Dudiebug/couchliteos/issues).

## New

- **TYPE ON PHONE in any app.** In a web browser, a web app or any other app,
  hold **Select (View / Share)** and press **Guide / PS**. The on-screen
  keyboard opens with a QR code: scan it with a phone on the same home network
  (or open the address shown), type, and send. The text comes back into the
  keyboard; choose **TYPE** or **TYPE + ENTER** to type it into the app.
  B / Circle on the QR code closes it again.
- **Your choice of shortcut.** Settings > CONTROLS > **TYPE ON PHONE SHORTCUT**:
  HOLD SELECT, PRESS GUIDE (the default), HOLD START, PRESS GUIDE, or OFF.
  During a Moonlight or chiaki-ng stream Guide still goes to the stream.
- **A TYPE ON PHONE key** on the on-screen keyboard does the same from the
  keyboard you already opened.

## Fixed

- **A 4K TV started in 1080p every time.** Some 4K TVs ask for 1080p at
  120 Hz. CouchLiteOS now picks the TV's full picture size at up to 60 Hz when
  you have not chosen one yourself, and Settings > DISPLAY and the Setup
  Wizard mark it as NATIVE. If you already picked 1080p, choose 3840x2160 in
  Settings > DISPLAY > RESOLUTION. If the screen stays black after the change,
  restart the box: it goes back to the earlier picture size and does not try
  again.
- **A TV that is slow to wake up no longer loses its picture size.** When the
  TV is not ready yet as CouchLiteOS starts, it now tries again for a few
  seconds instead of staying in the TV's own mode.

## Known limitations

- The phone's text can only contain letters, numbers and the symbols on a US
  keyboard. Other characters (accents, emoji) are left out, and the keyboard
  says so.

## Updating

A box with Settings > SOFTWARE UPDATE > UPDATE CHANNEL set to BETA gets this
beta from Settings > SOFTWARE UPDATE. Any other box: write the ISO to a USB
stick, boot it, and choose Settings > SOFTWARE UPDATE > UPDATE THE INSTALLED
SYSTEM. It keeps your settings and pairings.
