# MoonlightOS v0.1.9

MoonlightOS v0.1.9 gives the boot menu the same look as the launcher.

## New

- **Black-and-white boot menu.** The boot menu on UEFI and BIOS PCs now uses a
  high-contrast black-and-white look that matches the launcher. The selected
  entry is shown inverted, and the Debian splash picture is gone.
- **Dark installer.** The Install MoonlightOS entry uses a dark text theme.
  The advanced, automated, and rescue entries are still there.
