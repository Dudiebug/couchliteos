# CouchLiteOS v0.2.7

v0.2.7 keeps the Guide button and the PlayStation touchpad for the game you are
streaming, fixes going back to a running Moonlight, and checks for updates at
every start.

## Downloads

| File | For |
|---|---|
| `couchliteos-0.2.7-amd64.iso` | Intel and AMD graphics, NVIDIA Kepler and older (including the iMac Late 2013), Intel Macs, VMs |
| `couchliteos-0.2.7-nvidia-amd64.iso` | NVIDIA GeForce GTX 745/750, GTX 900 series and newer (up to RTX 40) |
| `SHA256SUMS` | Checksums for the ISOs |

## Changed

- **Guide goes to the stream.** While Moonlight or chiaki-ng is in front, the
  Guide / PS button no longer opens CouchLiteOS Home. It reaches the gaming PC,
  so Steam Big Picture and the PlayStation menu open as they should. To get back
  to Home during a stream, hold Select+Start (View+Menu) for 1.5 seconds, hold
  L3+R3 if you chose that in Settings > CONTROLS, or press the keyboard
  shortcut. Everywhere else Guide works as before.
- **The PlayStation touchpad goes to the stream.** The DualShock 4 and
  DualSense touchpad no longer moves the mouse pointer while you stream, and the
  box now lets Moonlight and chiaki-ng read the pad directly. Outside a stream
  the touchpad is a mouse again. For the gaming PC to see it as a touchpad,
  Sunshine must present your pad as a PlayStation controller (its default for a
  PlayStation pad).
- **Updates are checked at every start.** CouchLiteOS now looks for a new
  release each time it starts, then every few hours while it stays on, and
  retries after 10 minutes if the network was not ready. When there is one, a
  prompt on the Home screen asks if you want to open SOFTWARE UPDATE now. It
  asks once per release and never over a running app or stream. The SETTINGS
  row on Home and the SOFTWARE UPDATE row in Settings keep saying that an update
  is available. A check made in SOFTWARE UPDATE updates the Home screen too.

## Fixed

- **Back to Moonlight after Home.** Coming back to a running stream from Home
  could say Moonlight had no window. The box now tries every way of finding the
  window, including looking through the open windows, and records what it saw
  when none matches so it can be fixed for good.

## Updating

A box on 0.2.1 or newer gets this release from Settings > SOFTWARE UPDATE.
Boxes on 0.2.0 or older must be reinstalled once; see
[Updating](https://github.com/Dudiebug/couchliteos/wiki/Updating) in the wiki.
