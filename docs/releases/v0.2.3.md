# CouchLiteOS v0.2.3

v0.2.3 makes running apps usable from the couch: type into any app with the
controller, use the controller as a mouse in browsers, and open the Guide menu
over whatever is running.

## Downloads

| File | Hardware |
|---|---|
| `couchliteos-0.2.3-amd64.iso` | General: Intel and AMD graphics, NVIDIA Kepler and older (including the iMac Late 2013), Intel Macs, VMs |
| `SHA256SUMS` | Checksum for the ISO |

There is no NVIDIA ISO for this release. On a newer NVIDIA card (GTX 745 and up), the general ISO uses the open nouveau driver and Moonlight decodes the video in software.

## New

- **Type into any app with the controller.** Press Guide, pick the app and
  press X (Xbox) / Triangle (PlayStation). The on-screen keyboard opens over
  the app, and the text is typed into it when you choose TYPE or TYPE + ENTER.
- **Controller mouse for browsers and web apps.** In Firefox, Google Chrome and
  web apps added in Settings, the left stick moves a pointer, the right stick
  scrolls, A clicks, Y (Xbox) / Square (PS) right-clicks, B goes back, LB/RB
  page up and down, Start is Space, Back/Select is Esc, and X / Triangle opens
  the keyboard. Games and streaming clients keep the controller. Turn it on or
  off per app in the Guide menu.
- **Guide menu quick settings.** ACTIVE APPLICATIONS (Guide / PS / Home) now
  has VOLUME (Left/Right change it, A mutes) and CONTROLLER MOUSE rows.
- **Hardware video decoding for older NVIDIA GPUs (experimental).** On PCs
  that use nouveau, such as the iMac Late 2013, Settings > STREAMING > VIDEO
  DECODER FIRMWARE downloads NVIDIA's 325.15 driver from nvidia.com (27 MB,
  checked against a known checksum), extracts only the video decoder firmware
  on the PC, and keeps it on the USB drive. CouchLiteOS cannot ship that
  firmware itself. Moonlight switches to automatic decoding only after the
  decoder was seen working on that GPU; otherwise it stays on software.

## Fixed

- **Guide and Home now open the menu over a running app**, and RESUME brings
  the chosen app back to the front.
- **A tap of the Super (Windows) key** on a keyboard opens the Guide menu too.
- **What's New** after an update listed the 0.2.0 features and the rename
  notice again. It now lists what changed since the version you had.
- **Remote Desktop opened no window.** It now opens full screen.
- **Moonlight warned "no functioning hardware accelerated video decoder"** on
  PCs without one (nouveau) after its decoder was set back to automatic.
  CouchLiteOS now keeps Moonlight on software decoding there.
- **GENERATE SUPPORT FILE** left out the display, VA-API and Vulkan reports.
- **On-screen keyboard.** It could drop the first letters it typed.
- **Damaged settings files.** A corrupt Bluetooth power setting file no longer
  stops Bluetooth from applying the saved setting, and a damaged support-file
  status file is ignored.
- **ADD COMMAND** accepts environment values written as `A=1; B=2;`.

## Updating

A box on 0.2.1 or newer gets this release from Settings > SOFTWARE UPDATE.
Boxes on 0.2.0 or older must be reinstalled once; see
[Updating](https://github.com/Dudiebug/couchliteos/wiki/Updating) in the wiki.
