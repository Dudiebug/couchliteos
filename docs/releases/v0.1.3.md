# MoonlightOS v0.1.3

MoonlightOS v0.1.3 improves the launcher and fixes problems found while using
v0.1.2 on real hardware.

## Downloads

Verify the downloaded image before writing it:

```bash
sha256sum --check moonlightos-0.1.3-amd64.iso.sha256
```

## New

- **Triple-tap Esc to leave an app.** Press Esc three times quickly in
  Moonlight, chiaki-ng, or Firefox to close it and go back to the launcher.
  One or two presses still reach the app as usual.
- **Startup screen.** A black-and-white screen with a spinner shows while an
  app is starting.
- **Startup failure message.** If an app keeps failing to start, the launcher
  now tells you instead of quietly going back.

## Fixed

- **Apps misbehaved after Tailscale setup.** The launcher's keyboard and screen
  state is now restored when Tailscale setup closes.
- **Wrong IP address shown.** The launcher now shows the first real IPv4
  address instead of the loopback address.
- **Support export missed USB drives that were not mounted.** It now finds
  ordinary writable USB drives, mounts them safely for the export, checks the
  file, and unmounts them again.
- **The boot USB stick was offered as a support export destination.** It is no
  longer listed.

Moonlight 6.1.0, chiaki-ng 1.10.0, and Firefox ESR are unchanged.
