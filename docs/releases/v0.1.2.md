# MoonlightOS v0.1.2

MoonlightOS v0.1.2 adds display settings you can change with a controller and
a way to save a support file to a USB drive.

## Downloads

Verify the downloaded image before writing it:

```bash
sha256sum --check moonlightos-0.1.2-amd64.iso.sha256
```

## New

- **Settings page.** A full-screen, black-and-white Settings page you can use
  with a controller or keyboard.
- **Resolution and refresh rate.** Pick from the modes your display reports.
  A new mode shows for 15 seconds; confirm it with the controller or keyboard,
  or it switches back on its own.
- **Your display mode is remembered** for that display. If you connect a
  different display, MoonlightOS goes back to the default mode.
- **Save a support file to USB.** Pick a USB drive with the controller.
  The file holds hardware, graphics, audio, network, and system logs with
  sensitive values removed. App data, browser data, pairings, and Tailscale
  keys are never included.
- **Safe copy.** The file is checked after it is written, gets a checksum file
  next to it, and a failed copy leaves nothing half-written behind.

Moonlight 6.1.0, chiaki-ng 1.10.0, and Firefox ESR are unchanged. Closing any
app returns to the launcher.

## Known limitations

- Display switching, controllers, video decoding, audio, streaming quality, and
  USB export have not yet been tried on the target Dell OptiPlex.
