# CouchLiteOS v0.3.0-beta.4

**A fix for the third beta.** On the iMac Late 2013, and other PCs with older
NVIDIA graphics on the general ISO, the third beta showed only a green screen
after the boot picture. The TV interface there now draws the way the second
beta did. Everything else is the same as the third beta; see its notes below.
Please report what goes wrong on
[GitHub](https://github.com/Dudiebug/couchliteos/issues).

If your box shows the green screen: restart it, and choose Settings >
SOFTWARE UPDATE > RESTORE PREVIOUS VERSION if it comes back (or update from
the USB stick, below).

## Downloads

| File | For |
|---|---|
| `couchliteos-0.3.0-beta.4-amd64.iso` | Intel and AMD graphics, NVIDIA Kepler and older (including the iMac Late 2013), Intel Macs, VMs |
| `couchliteos-0.3.0-beta.4-nvidia-amd64.iso` | NVIDIA GeForce GTX 745/750, GTX 900 series and newer (up to RTX 40) |
| `SHA256SUMS` | Checksums for the ISOs |

## Fixed

- **A green screen after the boot picture** on PCs with older NVIDIA graphics
  (nouveau driver), the iMac Late 2013 among them. The third beta asked for
  OpenGL drawing there to make the interface faster; it now leaves the choice
  to GTK, as the second beta did. Intel and AMD graphics keep OpenGL.

## Testing

This fix was released quickly: the unit tests and a boot test ran, but not the
full set of install and update tests the other betas went through.

## Updating

A box on the second or third beta with UPDATE CHANNEL set to BETA gets this
beta from Settings > SOFTWARE UPDATE. Any other box: write the ISO to a USB
stick, boot it, and choose Settings > SOFTWARE UPDATE > UPDATE THE INSTALLED
SYSTEM. It keeps your settings and pairings.

# From the third beta

## New since the second beta

- **Every screen in the new look.** All Settings pages (DISPLAY, AUDIO,
  NETWORK, BLUETOOTH, CONTROLLERS, SOFTWARE UPDATE and the rest) and the Setup
  Wizard are drawn by the TV interface, in your theme, instead of opening a
  text window on top of it. If one of them cannot be drawn that way on a PC, it
  opens in the old text look as before.
- **A new on-screen keyboard.** The controller keyboard is drawn in the same
  look, with large keys along the bottom of the screen; the app you type into
  stays visible above it. It works as before: A types the key, Y deletes, B
  cancels, TYPE + ENTER sends the text and presses Enter.
- **WHAT'S NEW in pages.** The list of new features is shown as cards in two
  columns, a page at a time (right or A for the next page), instead of one
  long crammed list.
- **Moonlight in APPS.** APPS now has MOONLIGHT, which opens Moonlight's own
  list of gaming PCs, and REMOTE DESKTOP. The NETWORK category is gone from the
  home screen: Wi-Fi and network are under SETTINGS > NETWORK.
- **The gaming PC on the home screen.** The top of the home screen always shows
  the paired gaming PC and whether it is ONLINE, ASLEEP, NOT FOUND or has NO
  SUNSHINE running.
- **A boot picture from the first second.** The box now shows its boot picture
  as soon as the PC hands over to it, instead of a black screen with text, and
  the picture carries on into the home screen's start animation.

## Fixed

- **A box woke the gaming PC instead of connecting.** The box now asks every
  address of the gaming PC at once (home network, the address you entered, the
  remote address and IPv6) and only sends a wake-up when none answers.
- **No music on some PCs** (the iMac Late 2013 among them). The music now plays
  through PipeWire like the other sounds, and starts again by itself if its
  player stops. Problems are written to `/var/log/couchliteos/music.log`, which
  the support file includes.
- **APPS was empty** on some boxes. It now lists installed apps right away, and
  Flatpak apps are detected correctly.
- **Lag on older PCs.** The TV interface picks OpenGL drawing where Vulkan
  would run on the processor (Intel and older NVIDIA graphics), draws the wave
  at a lower resolution above 1080p, keeps finished frames instead of drawing
  them again, and turns animations down by itself when frames come too slowly.
  Settings are read in the background, so the home screen no longer stalls when
  you open them. Nothing was taken away: the wave, sparkles, sounds and music
  are all still there.
- **Home while a game starts** goes back to the home screen as the loading
  screen says, and the game keeps starting; a notice says when it is ready.
- **The tour no longer hides** behind the update screen after an update.
- **The loading screen** shows the cover or icon of what is starting.
- **A slow start** no longer leaves the box on the boot picture: the saved
  display mode and AUTO-STREAM wait until the home screen is up, and a step
  that fails no longer stops the rest.

## Correction to the second beta's notes

The second beta's notes said the box shows its logo and a loading animation
while it starts. On most PCs it did not: the screen stayed black, or showed
text, until the launcher started. This beta installs the boot picture properly
(above). On some PCs with AMD or NVIDIA graphics the screen can still stay black
for a few seconds before the picture appears.

## Known limitations

- INSTALL TO THIS STICK (installing CouchLiteOS onto the USB stick you started
  from) is not in 0.3.0; it is planned for a 0.3.x update.
- If the TV interface cannot start on a PC, the box starts the classic
  interface by itself.
- The music has no setting on screen yet. To turn it off, set `music = off`
  under `[appearance]` in `/var/lib/couchliteos/config.ini`, or put your
  own track in `~/.local/share/couchliteos/music/`.
- On PCs without 3D graphics the wave stands still and animations are shorter.
- A web browser added on a live USB stick is gone after a restart, even with a
  persistence stick; add it again, or install CouchLiteOS to the disk.
- TYPE ON PHONE sends the text over your home network without encryption. For
  a password, use it only on a home network you trust.
- Saving the current system needs about 7 GB free on the disk, besides the
  download. 32 GB disks or larger are recommended.
- Game covers from SteamGridDB need your own SteamGridDB key in Settings >
  APPEARANCE > ARTWORK; without one, covers come from Moonlight and Steam.
