# MoonlightOS v0.1.7

MoonlightOS v0.1.7 adds a setup wizard, an on-screen keyboard, and your own
apps in the launcher.

## New

- **Setup Wizard.** Runs at first boot, and you can run it again later.
- **Your own apps.** Apps are now listed in simple INI files, so you can add
  your own command or web apps. A new Applications settings screen manages them.
- **Web apps in Firefox kiosk mode.** Custom web entries open full screen in
  Firefox.
- **On-screen keyboard.** A full-screen text keyboard opens with Guide/Home +
  X/Square on a controller, or F12.
- **Tools in their own window.** Terminal, Tailscale setup, diagnostics, and
  the network tool (`nmtui`) open in a separate full-screen window, so they
  cannot interrupt the launcher.
- **Bluetooth search keeps running** until you leave Bluetooth settings, turn
  Bluetooth off, or start an action. RESCAN restarts it.
- **More controllers recognized**, using the device rules from Debian's
  `steam-devices` package.
- **Privacy.** App details in diagnostics and support files leave out
  environment values, arguments, and URLs.

Moonlight, chiaki-ng, Firefox, support export, display mode rollback, USB/IP,
and Tailscale work as before.

## Known limitations

- Steam is not included; only the controller device rules are.
- The on-screen keyboard covers the whole screen; it is not an overlay.
- Custom apps must already be installed on the system.
- Live USB persistence needs the same setup as before.
- Bluetooth, controllers, audio, displays, TVs, HDR, graphics, and the
  on-screen keyboard have not yet been tried on real hardware.
