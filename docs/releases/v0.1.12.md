# MoonlightOS v0.1.12

MoonlightOS v0.1.12 adds an image for the Apple iMac Late 2013 and a
controller-friendly Remote Desktop client.

## Downloads

| File | Hardware |
|---|---|
| `moonlightos-0.1.12-amd64.iso` | Dell OptiPlex 7010 Micro (Intel UHD 770) |
| `moonlightos-0.1.12-imac2013-amd64.iso` | Apple iMac Late 2013 with NVIDIA Kepler (iMac14,2 / iMac14,3) |
| `SHA256SUMS` | Checksums for both ISOs (`sha256sum -c --ignore-missing SHA256SUMS`) |

## New

- **iMac Late 2013 image.** Its NVIDIA Kepler graphics use the open nouveau
  driver. Moonlight starts with software H.264 at 1080p60; 1440p can still be
  picked in Moonlight's settings.
- **iMac hardware support.** Broadcom BCM4360 Wi-Fi, the built-in Ethernet,
  Apple keyboard function keys, and temperature sensors in System Diagnostics.
  To boot the USB stick, hold Option and choose **EFI Boot**.
- **Remote Desktop.** Settings > Remote Desktop adds, edits, and deletes saved
  connections (name, host, port, username, domain, native/fit/custom
  resolution, full screen, audio, clipboard) with a controller and the
  on-screen keyboard.
- **Passwords are asked when you connect.** You can choose to save one; it is
  stored unencrypted, readable only by the system, and never included in
  support files.
- **Server certificates.** The first connection shows the server's fingerprint
  and trusts it. If the certificate changes later, the connection is blocked.
- **Remote Desktop on the launcher.** Pin any connection with its own label,
  position, and controller shortcut (LB, RB, View, Menu, or F5-F8).
- **Remote Desktop works like the other apps.** Home/Guide resumes or closes it,
  and it comes back after a crash. A wrong password is never retried.
- **On-screen keyboard from the controller.** In launcher text fields, press X
  (Xbox) or Triangle (PlayStation). Password fields stay hidden.
- **System Diagnostics** shows the image type, graphics driver, network
  drivers, and sensors.
