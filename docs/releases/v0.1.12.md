# MoonlightOS v0.1.12

MoonlightOS v0.1.12 adds a second hardware target, the Apple iMac Late 2013,
and a controller-friendly Remote Desktop client. This is a **draft**: publish it
only after the iMac hardware checklist in `docs/TESTING.md` passes.

## Downloads

| File | Hardware |
|---|---|
| `moonlightos-0.1.12-amd64.iso` | Dell OptiPlex 7010 Micro DCC36X3 (Intel UHD 770) |
| `moonlightos-0.1.12-imac2013-amd64.iso` | Apple iMac Late 2013 with NVIDIA Kepler (iMac14,2 / iMac14,3) |
| `SHA256SUMS` | Checksums for both ISOs (`sha256sum -c SHA256SUMS`) |

## iMac Late 2013 build profile

- New `imac2013` build profile: `sudo make build PROFILE=imac2013`. The Intel
  image is unchanged apart from Remote Desktop.
- NVIDIA Kepler runs on nouveau and Mesa only. The build fails if a
  proprietary NVIDIA package or module appears (Kepler's last proprietary
  driver has no GBM, so Cage cannot run on it).
- Moonlight defaults to software H.264 at 1080p60; 1440p stays selectable in
  Moonlight's settings.
- Broadcom BCM4360 Wi-Fi through `broadcom-sta-dkms`: `wl.ko` is built for the
  image kernel inside the build and checked in the final image. Conflicting open
  drivers are blacklisted.
- BCM57766 Ethernet firmware, `hid_apple` function-key mode, and `applesmc`
  sensors in System Diagnostics.
- Boot with Option → **EFI Boot**. `sudo moonlightos-hardware-report` records
  the machine identification for `docs/IMAC-2013.md`.

## Remote Desktop

- FreeRDP 3 SDL client (`freerdp3-sdl`) on Cage's Wayland socket, no Xwayland.
- Settings → Remote Desktop: add, edit, and delete saved connections (name,
  host, port, username, domain, native/fit/custom resolution, fullscreen, audio,
  clipboard) with a controller and the on-screen keyboard.
- Passwords are prompted at connect time by default and passed to FreeRDP on
  standard input only. An optional saved password is stored root-only (0600) and
  unencrypted; support archives never include it.
- Server certificates are trusted on first use after showing the SHA-256
  fingerprint; a changed certificate blocks the connection.
- Any connection can be pinned to the launcher with its own label, position, and
  controller shortcut (LB, RB, View, Menu, or F5–F8).
- Sessions use Home/Guide resume/close and systemd crash recovery like the
  other applications; authentication failures are never retried.

## Other changes

- Both ISOs stay under GitHub's 2 GiB asset limit: firmware packages are no
  longer duplicated into the ISO for the text installer (the live and installed
  systems keep their firmware), and the iMac image installs a curated firmware
  list.
- A controller now opens the on-screen keyboard in launcher text fields (X on
  Xbox pads, Triangle on PlayStation pads). Password fields open it masked.
- System Diagnostics reports the build profile, GPU kernel module, network
  drivers, and sensors.
- Local tooling: Hyper-V and Proxmox VE test-VM scripts, `make release-assets`
  (checksums and GitHub asset-size check), and a draft-only release script.
  Nothing depends on GitHub Actions.

## Testing status

Source, unit, static, and mutation tests pass; the RDP path was exercised end to
end against xrdp in the lab. QEMU results are recorded in `docs/TESTING.md`.
**No physical iMac or OptiPlex result is recorded yet**; the draft stays
unpublished until the hardware checklist passes.
