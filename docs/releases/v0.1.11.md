# MoonlightOS v0.1.11

MoonlightOS v0.1.11 adds Google Chrome. Firefox ESR stays.

## New

- **Google Chrome Stable**, installed from Google's signed Debian repository.
  Chromium is not installed.
- **Chrome in the launcher.** It runs natively on Wayland, keeps its profile,
  and opens from the controller-friendly launcher.
- **Web apps use Chrome.** New web apps you add open in Google Chrome kiosk
  mode.
- **Support file** shows the installed Chrome version and where it came from,
  without collecting browser profiles.

## Known limitations

- Google Chrome includes its standard Linux Widevine support, but Disney+ does
  not currently list ordinary Linux systems as supported. MoonlightOS does not
  work around streaming services' device rules or DRM.
