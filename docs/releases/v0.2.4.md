# CouchLiteOS v0.2.4

v0.2.4 adds brightness and volume keys, a Home shortcut for any controller or
keyboard, pointer speed settings, and an on-screen keyboard that no longer
covers the app you type into.

## Downloads

| File | Hardware |
|---|---|
| `couchliteos-0.2.4-amd64.iso` | General: Intel and AMD graphics, NVIDIA Kepler and older (including the iMac Late 2013), Intel Macs, VMs |
| `SHA256SUMS` | Checksum for the ISO |

## New

- **Brightness and volume keys work.** Laptop and keyboard brightness keys
  change the built-in screen's backlight, and the volume and mute keys change
  the volume, in the launcher and in every app (including Moonlight and Remote
  Desktop). The Guide menu has a BRIGHTNESS row on PCs with a built-in screen.
- **Home from any controller or keyboard.** Guide/PS still goes Home. Holding
  SELECT+START for 1.5 seconds now does too, for pads without a Guide button;
  Settings > CONTROLS > HOME SHORTCUT can switch that to L3+R3 or turn it off
  (GUIDE ONLY). A keyboard goes Home with Ctrl+Alt+H (KEYBOARD HOME SHORTCUT
  turns it off) as well as the Super key; it also works during a stream or
  Remote Desktop session. While SELECT+START is the Home shortcut, a SELECT or
  START tap acts when the button is released, so starting the hold never
  triggers them.
- **Mouse speed settings.** Settings > CONTROLS has CONTROLLER MOUSE SPEED and
  MOUSE SPEED (for a real mouse or touchpad): SLOW, NORMAL, FAST, VERY FAST.

Settings > CONTROLLER BUTTONS is now Settings > CONTROLS; the button help is
its CONTROLLER BUTTONS row.

## Fixed

- **The on-screen keyboard covered the whole screen.** It is now a panel along
  the bottom (40% of the screen), and the app you type into stays visible
  above it.
- **What's New** after an update now shows only this release's changes. When
  you skipped releases, it points to the release notes for the rest.
- **Text too big after a smaller picture size.** After switching, for
  example, a 4K TV to 1080p in setup or in Settings > DISPLAY, the text kept
  its 4K size. The launcher now restarts for a new picture size so the text
  fits it, and setup carries on at the sound check. With an app open, the
  text catches up on the next start.
- Ctrl+Alt+H in the setup wizard skipped the current step, and the Home
  request it left opened the running applications after setup. Setup now
  ignores it, as it does Guide.
- If the launcher saved settings while the video decoder firmware was
  downloading, Moonlight could stay on software decoding. The next restart now
  switches it to automatic as intended.

## Docs

- Troubleshooting has a "Moonlight stream is black" section for host-side
  causes (no monitor on the gaming PC, Remote Desktop holding the screen, lock
  screen, protected video).

## Updating

A box on 0.2.1 or newer gets this release from Settings > SOFTWARE UPDATE.
Boxes on 0.2.0 or older must be reinstalled once; see "Updating to a new
release" in the install guide.

## Testing status

Unit and static tests pass (24 suites, 2145 launcher tests). The release ISO
was booted in a VM at 1080p and 4K: setup at 4K restarts with text that fits
and resumes at the sound check, Ctrl+Alt+H goes Home and no longer skips a
setup step, the on-screen keyboard is a bottom panel with the app visible
above it, and What's New after an update from 0.2.3 lists only 0.2.4. Not yet
tested on real hardware: see the 0.2.4 lines in `docs/TESTING.md`.

The release build took 25m08s. Release builds do not reuse the installed
system yet, so this release is not faster to build than 0.2.3; that is planned
for 0.3.0.
