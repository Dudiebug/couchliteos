# MoonlightOS v0.1.13

MoonlightOS v0.1.13 replaces the per-machine images with two ISOs that detect
the hardware at boot: a **general** ISO for Intel, AMD, older NVIDIA cards,
Intel Macs, and VMs, and an **NVIDIA** ISO with NVIDIA's proprietary driver for
GeForce GTX 900 to RTX 40 cards. This is a **draft**: publish it only after the
hardware checklist in `docs/TESTING.md` passes.

## Downloads

| File | Hardware |
|---|---|
| `moonlightos-0.1.13-amd64.iso` | General: Intel and AMD graphics, NVIDIA Kepler and older (including the iMac Late 2013), Intel Macs, VMs |
| `moonlightos-0.1.13-nvidia-amd64.iso` | NVIDIA GeForce GTX 900 to RTX 40 (Maxwell to Ada); falls back to nouveau on other GPUs |
| `SHA256SUMS` | Checksums for both ISOs (`sha256sum -c SHA256SUMS`) |

NVIDIA RTX 50 (Blackwell) cards are not supported yet. The iMac Late 2013 no
longer has its own ISO; use the general one.

## Two ISOs, one hardware detector

- `moonlightos-hwdetect` runs on every boot before udev loads drivers and
  writes that machine's module policy under `/run` only, so a USB stick moved
  between machines starts clean. `/usr/libexec/moonlightos-hwdetect report` and
  System Diagnostics show what it chose.
- NVIDIA ISO: NVIDIA's 550 driver, built with DKMS for the image kernel, with
  GBM for Cage, Vulkan, and NVDEC/CUDA libraries. It loads only for GPUs on the
  driver's supported list; any other NVIDIA GPU gets nouveau. A new **Start
  MoonlightOS (Basic Graphics)** boot entry forces nouveau.
- When the display driver is nouveau, Moonlight starts with software H.264
  instead of failing to find a hardware decoder. Setting `codec` or `decoder`
  in `config.ini` overrides it.
- Broadcom `wl` Wi-Fi is on both ISOs and used only for chips on its list (for
  example the iMac's BCM4360); other Broadcom chips keep the open drivers.
  Apple machines get `applesmc` sensors; Apple keyboards default to F1-F12.
- One curated firmware set for Intel, AMD, and NVIDIA graphics, Intel SOF and
  Cirrus audio, common Wi-Fi/Bluetooth/Ethernet chips, and Intel and AMD CPU
  microcode, plus VA-API drivers for Intel (iHD and i965) and AMD.
- The `intel` and `imac2013` profiles remain buildable as legacy profiles but
  are no longer release assets.

## Other changes

- The static test suite's negative checks now actually fail it: a negated
  command never trips `set -e`, so 34 checks in the suite and four in the
  in-image QEMU smoke test could not fail before.
- The QEMU smoke test checks that hardware detection ran and, on the NVIDIA
  ISO, that the proprietary driver stays unloaded without an NVIDIA GPU.
- System Diagnostics and `moonlightos-hardware-report` include the hardware
  detection summary.

## Licenses

The NVIDIA ISO contains NVIDIA's proprietary driver and GSP firmware from
Debian 13's `non-free` and `non-free-firmware` areas, unmodified apart from the
DKMS build of the kernel module. Both ISOs contain Broadcom's `wl` driver built
the same way. See `THIRD_PARTY_NOTICES.md`. The general ISO contains no
proprietary NVIDIA driver.
