# CouchLiteOS v0.2.6

v0.2.6 fixes the Home screen saying no gaming PC was paired when one was, and
removes the notice for people who do not use a gaming PC.

## Downloads

| File | For |
|---|---|
| `couchliteos-0.2.6-amd64.iso` | Intel and AMD graphics, NVIDIA Kepler and older (including the iMac Late 2013), Intel Macs, VMs |
| `couchliteos-0.2.6-nvidia-amd64.iso` | NVIDIA GeForce GTX 745/750, GTX 900 series and newer (up to RTX 40) |
| `SHA256SUMS` | Checksums for the ISOs |

## Changed

- **No more "none paired yet" notice.** The line under the title on the Home
  screen no longer asks you to pair a gaming PC. Many people use CouchLiteOS only
  for PlayStation Remote Play or as a lightweight desktop, so it now stays empty
  until a gaming PC is paired.

## Fixed

- **A paired gaming PC was not recognised.** The Home screen read the Moonlight
  settings file in the wrong layout, so a PC you had paired in Moonlight showed
  as "none paired yet". It now reads the file the way Moonlight writes it, so the
  line under the title shows the PC's state (ready, asleep, or not answering).
  The same fix makes the STREAM row, waking a sleeping PC, and starting a stream
  automatically see your paired PC.

## Updating

A box on 0.2.1 or newer gets this release from Settings > SOFTWARE UPDATE.
Boxes on 0.2.0 or older must be reinstalled once; see
[Updating](https://github.com/Dudiebug/couchliteos/wiki/Updating) in the wiki.
