# MoonlightOS v0.1.5

MoonlightOS v0.1.5 is a reliability release with fixes found while using
v0.1.4 on real hardware. It also removes the triple-Esc shortcut from v0.1.3;
apps still return to the launcher when they close.

## Downloads

This release contains only the ISO, with no separate checksum file.

## Fixed

- **Tailscale setup.** Closing it now returns to the same launcher session. It
  shows whether it connected, was closed, or failed, ignores old sign-in links,
  and returns on its own once you have signed in. Sign-in keeps going in the
  background if you close the setup screen.
- **Support file.** It now includes DNS settings and the Wi-Fi and USB/IP
  package versions.
- **Support export.** It creates exactly one file, checks all of it, and
  reports success only after the USB drive was safely unmounted.
- **USB/IP** now starts correctly, and stopping it no longer reports a false
  error.
- **Wi-Fi hardware** can now be turned on when Wi-Fi is configured.
